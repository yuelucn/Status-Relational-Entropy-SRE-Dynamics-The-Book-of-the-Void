## 1. 实验设定（保留，未改动）

* 前 30 步（`CORE_SIZE = 30`）注入符合兰姆-奥森涡高斯分布与非对称单向旋转速度场的两点关联耦合方阵；
* 随后移交自组织网络自由生长至 $N=100$，取 $\Lambda = 0.05$；
* 以 MDS 将关联矩阵重构为三维流形坐标。

```python
M_core = generate_oseen_vortex_initial_matrix(core_size=30)
for n in range(core_size, steps):
    ratio = (lam * d_matrix) / (np.abs(M @ M) + 1)
    activate_matrix = rand_matrix >= (1.0 - 1.0 / (1.0 + ratio))
distance_matrix = np.sqrt(np.clip(2.0 - 2.0 * (M_main / 1.0), 0, None))
coordinates_3d = MDS(n_components=3, dissimilarity='precomputed').fit_transform(distance_matrix)
```

按 `main_CN.md` v2 的定标，本实验的 $\Lambda=0.05$ 落在**过渡区上沿**：
模式 A 相图给出 $\Lambda=3.16\times10^{-2}$ 时结构密度 0.4483、$\Lambda=10^{-1}$ 时 0.3809，
故本工况的结构密度约 0.44，谱斜率约 −1.83。它既非"层流"也非"极端湍流"。

## 2. 观测一：$\Phi(N)\equiv 1.0000$ 的正确解读

**原始观测**：序参量随步数推进死死卡在 1.0000，无任何波动。

**修正后的解读**：在实现中 $\Phi$ 定义为

$$\Phi(n) = \frac{\text{本步存活通道数}}{n}$$

分母 $n$ 是当前历史节点数，分子至多等于 $n$。因此 $\Phi\equiv 1$ 等价于
**每一步的所有前沿通道都存活**，即 $p_{\text{prune}}\approx 0$，系统处于**零耗散极限**。

这是一个平凡结果，而不是"抗噪锁死"的证明——理由很简单：
若剪枝概率本就为零，则不存在任何"噪声被抵抗"的事件可供观测。
在零耗散极限下 $\Phi\equiv1$ 是**构造使然**，与初值是否为奥森涡无关；
换成任意初值、甚至纯随机初值，只要 $p_{\text{prune}}\approx0$，同样会得到 $\Phi\equiv1$。

**要检验抗噪性，应当这样设计**：固定初值，在 $\Lambda$ 上做扫描，
观察 $\Phi(\Lambda)$ 的衰减曲线，并比较奥森涡初值与无手性随机初值的差异。
按 `main_CN.md` §6.2，$\Phi$（此处即结构密度）随 $\Lambda$ 从 0.49 平滑衰减到 0.003，
且衰减曲线的形状才是真正携带信息的可观测量。原实验只取了曲线上的一个点。

> 结论：该观测不能支持"奥森涡拟谱界猜测的闭环证明"。它至多说明
> 在 $\Lambda=0.05$ 这一特定工况下剪枝尚未激活。

## 3. 观测二：残差 $8.93\times10^{-1}$ 的正确解读

**原始观测**：MDS 重构残差为 $0.893$。

**修正后的解读**：无论采用经典 MDS 还是迭代 SMACOF，该残差都是
**嵌入误差**——它度量的是「二元相异度矩阵在三维欧氏空间中的不可表示程度」。

它与"内蕴非欧几何曲率"之间没有已建立的定量关系。要使这种解读成立，需要：

1. 先估计数据的**本征维数**（如用最大似然估计或两点相关维数），确认真实维数高于 3；
2. 再用与嵌入无关的拓扑量（持续同调的 Betti 数、离散曲率）独立测量"卷曲度"；
3. 最后建立两者之间的对应关系。

在此之前，$0.893$ 只应被报告为"三维嵌入不能完全表示该二元度规"，
而三维嵌入本身只是可视化选择，并非物理维数。
这一数值也可能部分来源于 MDS 迭代未收敛（见 `main_CN.md` §6.1 的方法学对照）。

## 4. 该实验在证据链中的实际位置

修正之后，本实验能够支持与不能支持的结论如下。

**能够支持**：

* 奥森涡型初值可以在离散算子链中被注入，并在后续演化中保留其手性特征；
* 在 $\Lambda=0.05$ 工况下，系统维持约 0.44 的手性通道密度，
  且手性场呈现幂律标度（斜率约 −1.83），与 `main_CN.md` §6.6 一致。

**不能支持**：

* 拟谱界猜测的任何形式的证明（需要参数扫描而非单点）；
* 拓扑抗噪锁死（需要对照实验：手性初值 vs 无手性初值）；
* 内蕴非欧曲率（需要本征维数与独立拓扑量）；
* 刚性中轴的涌现（对度规重构方法敏感，见 `main_CN.md` §6.5）。

## 5. 建议的补做实验

若要使本报告达到可发表标准的实证强度，建议按以下顺序补做：

1. **$\Lambda$ 扫描**：以同一奥森涡初值扫 $\Lambda\in[10^{-4},10^{2}]$（对数 17 点、≥5 种子），
   报告结构密度与谱斜率曲线。可直接复用 `sre_core.py`。
2. **初值对照**：奥森涡初值 vs 高斯无手性初值 vs 均匀随机初值，
   在同 $\Lambda$ 下比较结构密度与拓扑荷 $\mathcal{Q}=\operatorname{Tr}(A\mathbf{D})$ 的演化。
3. **本征维数估计**：用两点相关维数或 MLE 估计流形本征维数，
   判定三维嵌入是否确实欠表示，再讨论"曲率"。
4. **嵌入无关性检验**：用持续同调计算 $\beta_0,\beta_1$，
   检验"核-壳"结构是否独立于 MDS 准则而存在。
